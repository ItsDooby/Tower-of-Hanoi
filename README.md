# Tower of Hanoi

A terminal-based Tower of Hanoi game written in Java.

## How to run
1. Compile: `javac TowerOfHanoi.java`
2. Run: `java TowerOfHanoi`

## How to play
- Choose a difficulty level at the start
- Type `A`, `B`, or `C` to select a stack to move from
- Type `A`, `B`, or `C` to select a stack to drop onto
- Illegal moves are rejected and the piece is returned
- Move all discs from stack A to either B or C to win

## Features
- Variable difficulty — play with as many discs as you want
- Perfect score calculator — shows the minimum moves needed before you start
- Move counter
- Illegal move detection and piece recovery
